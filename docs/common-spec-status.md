# 水滴キャッチ 共通対応 Draft

## この変更
既存ゲームを維持し、任意の開始時名前、ホームと結果のX共有、15言語の表示、SEと音設定、ランキング詳細へのリンク、上位30件の読取表示・再試行、実際のrank_noによる同順位表示、通常の8列登録応答の整合確認を含む候補です。

65秒到達だけではクリアにならず、その後のタップでクリアします。リタイアはクリアへ変更しません。既存ゲーム識別値 suiteki_catch と採点を維持します。

## 検証範囲
公開用テストは Node 組込みモジュールだけを使用し、抽出した関数へ偽の通信応答を渡します。ゲーム全体・実API・実音声・ブラウザを実行するものではありません。登録応答の整合検証は、永続保存、冪等性、参加者の一意性を証明しません。

## 公開前に必要な残作業
- 接続キーは元ファイルのプレースホルダーのままです。この状態で実ランキング・登録が動作するとは扱いません。認証・接続設定を別途確認します。
- 共有URLは既存Codeberg URLです。GitHub Pagesの実公開・動作確認後に正式URL切替を行います。
- Pages配備、CI、実ブラウザ/iPhone操作・聴感確認は未実施です。このPRにworkflowや配備設定は含めません。
- 既存の名前をキーにした集計と独立参加者識別の差、端末/公開元をまたぐ引継ぎ、登録失敗時の永続的な重複防止は未解決です。
- 計測、実験場の登録リンク切替、匿名プレイ計測は別の連携作業です。DBや既存スコアは変更していません。
- ランキング行全体のスキーマ検証（null行など）、名前の互換フィールド処理、全翻訳の自然さ・画面確認は引き続き検証が必要です。今回のスコア列検証はこれら全体の保証ではありません。

## 公開後の対応予定
実際のゲーム画面を使ったサムネイルと共有カードを確認・追加します。現時点で画像設定済みとはしていません。

これらの結果とCI・公開・実機受入は別々に記録します。

## ランキングのスコア列検証
最高記録では `best_score`、初回記録では `first_score` だけを表示します。数値型の整数かつ -2147483648〜2147483647 の範囲を受け入れ、実際の 0 と過去の負数も保持します。欠落、null、文字列、真偽値、小数、非有限値、範囲外値は「—」とし、`score` やその他の旧別名、別タブの値では補いません。

既存の表示単位、rank_no の同順位、サーバー順、同名行、最大30件、RPC名と引数、登録応答検証は変更しません。共有数値ヘルパーの他用途にも変更を加えません。

追加の `node tests/ranking-score-strict.cjs` は両方の実読取関数から実描画関数までを選択して、偽の6列応答と不正値を検証します。既存4ファイルと合わせた個別テストに加え、公開物とは別のローカル比較でHTML全体が4か所のランキング編集だけであること、README・4ヘルパーなどの不変を確認します。全ゲーム実行や実サーバー確認を代替するものではありません。
